# AGENTS.md

This repository contains beginner-oriented documentation for Kimai.

Before modifying documentation:

1. Read `doc/project-scope.md`.
2. Read `doc/writing-guide.md`.
3. Consult the current official Kimai documentation for factual product behavior.
4. Do not document installation, infrastructure, command-line administration, APIs, or plugin-specific configuration unless the project scope has explicitly changed.
5. Write for a reader who does not already understand Kimai.
6. Explain why a choice matters before explaining where to click.
7. Distinguish documented Kimai behavior from project recommendations and fictional examples.
8. Prefer durable web-interface breadcrumbs over screenshots.  Add screenshots only when spatial context materially helps the reader.
9. Link to upstream Kimai reference documentation rather than copying substantial passages from it.
10. Do not assume that a feature should be configured merely because Kimai provides it.
11. Keep examples internally consistent across pages where practical.
12. Preserve historical data in recommendations.  Prefer hiding, deactivating, or otherwise retaining used records when Kimai's documented behavior makes deletion destructive.

When current Kimai behavior differs from this repository, update the guide and its supporting explanation.  Do not silently preserve obsolete instructions for the sake of consistency.
