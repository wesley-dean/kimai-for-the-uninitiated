# Kimai for the Uninitiated

You have a working Kimai installation and an administrator account.  Now what?

Kimai is flexible, and that flexibility means that the web interface can present choices before a new administrator understands their consequences.  This guide is intended to fill that gap.

It will not teach you how to install or host Kimai.  Instead, it will help you turn an empty installation into a small, understandable time-tracking and invoicing system using the web interface.

## What this guide adds

The [official Kimai documentation](https://www.kimai.org/documentation/) is the authoritative reference for Kimai features and behavior.  Use it when you need to know everything a feature can do.

Use this guide when your questions sound more like these:

- What should I create first?
- Is this a customer, a project, or an activity?
- Which features do I actually need?
- Where should my hourly rate live?
- Do I need teams or custom roles?
- What choices will be annoying to reverse later?
- How can I tell whether I configured something correctly?

## Where to begin

Start with [Start here](start-here/index.md).  The first few pages build the mental model that makes the rest of Kimai easier to understand.

When you are ready to work with actual records, continue with [Using Kimai](using-kimai/index.md), which walks through recording time, reviewing it before billing, and creating and managing invoices.

More advanced administration will be layered around that beginner path rather than placed in front of it.
