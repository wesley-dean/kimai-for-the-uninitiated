# Kimai for the Uninitiated

Kimai for the Uninitiated is an unofficial, beginner-oriented guide for people who have a working Kimai installation but do not yet know how to configure or use it.

The official Kimai documentation is the authoritative reference for what Kimai can do.  This project has a different purpose: help a new administrator understand what to do next, why a choice matters, what can safely wait, and how the pieces fit together.

The guide assumes that Kimai is already installed and that the reader can sign in through the web interface.  Installation, infrastructure, command-line administration, APIs, and plugin-specific configuration are outside the project's scope.

## Read the guide

The documentation is published with GitHub Pages.  Until the first Pages deployment is complete, the source material is available under [`docs/`](docs/).

Start with [`docs/start-here/index.md`](docs/start-here/index.md).

## Project principles

- Write for someone who does not already understand Kimai.
- Explain why a decision matters before explaining where to click.
- Distinguish documented Kimai behavior from recommendations and examples.
- Prefer a small, understandable starting configuration over configuring every available feature.
- Link to the official Kimai documentation for authoritative reference material rather than reproducing it.
- Use the Kimai web interface for the workflows documented here.

See [`doc/project-scope.md`](doc/project-scope.md) and [`doc/writing-guide.md`](doc/writing-guide.md) for the project's editorial contract.

## Status

This project is in its initial bootstrap phase.  The first milestone is a complete beginner journey from an empty Kimai configuration to recording time and producing an invoice.
